Two orbs, one halo each

I kept two participants rather than a single shared waveform: with interruptions allowed, both sides can make sound at once, and two fixed positions answer “who is talking?” faster than one line that changes owner. The glow is replaced by a calm solid halo that scales with level, and only the speaker turns indigo. Press Play on this artboard to try it.

Level → visual

The raw 0–1 level is smoothed (fast attack, slow release), gated, and put on a perceptual curve. Then it drives two CSS properties only, so no layout shift.

smooth += (raw − smooth) × (raw > smooth ? 0.5 : 0.12)
v       = clamp((smooth − 0.02) / 0.5, 0, 1) ^ 0.6
scale   = 1 + 0.35 × v
opacity = speaking ? 0.14 + 0.36 × v : 0
speaking: v > 0.08 for 120ms → on · below for 350ms → off

Turn-taking: when you start talking over the interviewer (barge-in), both tiles can be on for a moment. As soon as the server cuts the AI audio, the interviewer’s level drops and its tile goes idle on its own. The caption under the stage switches to “Go ahead, the interviewer is listening”. There’s no push-to-talk control anywhere.

Implementation

Write the level to a CSS variable from requestAnimationFrame. Don’t put it in React state, or you get 60 re-renders a second. Only call setSpeaking when the debounced value flips.

// useVoiceLevel.ts
export function useVoiceLevel(ref, getLevel, muted, onSpeaking) {
  useEffect(() => {
    let raf = 0, smooth = 0, on = false, pending = 0;
    const tick = (t) => {
      const raw = muted ? 0 : getLevel();
      smooth += (raw - smooth) * (raw > smooth ? 0.5 : 0.12);
      const g = Math.min(Math.max((smooth - 0.02) / 0.5, 0), 1);
      const v = Math.pow(g, 0.6);
      const want = v > 0.08;
      if (want === on) pending = t;
      else if (t - pending > (want ? 120 : 350)) {
        on = want; pending = t; onSpeaking(on);
      }
      ref.current?.style.setProperty("--level", v.toFixed(3));
      raf = requestAnimationFrame(tick);
    };
    raf = requestAnimationFrame(tick);
    return () => cancelAnimationFrame(raf);
  }, [muted]);
}

/* VoiceTile halo, Tailwind v4 */
.voice-halo {
  @apply absolute inset-0 rounded-full bg-primary opacity-0;
  transform: scale(calc(1 + 0.35 * var(--level, 0)));
  transition: transform 80ms linear, opacity 150ms ease-out;
}
[data-speaking="true"] .voice-halo {
  opacity: calc(0.14 + 0.36 * var(--level, 0));
}
@media (prefers-reduced-motion: reduce) {
  .voice-halo { transform: scale(1.12); transition: none; }
  [data-speaking="true"] .voice-halo { opacity: 0.3; }
}
